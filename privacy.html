JARVIS Privacy

JARVIS sends messages entered into the chat to its AI provider so it can generate responses. The application backend does not intentionally store chat conversations; AI requests are sent with storage disabled where supported.

API security

The Gemini API key is kept on the server as a Vercel environment variable and is not included in the public website code.

Abuse protection

The public API uses request-size limits, origin checks and a per-IP request limit to reduce automated abuse and unexpected API usage. These limits are best-effort and may reset when server instances restart.

Voice

If you use voice input, your browser's speech-recognition features handle microphone processing according to your browser and device settings.

Contact

For questions about this project, use the contact method provided by its owner.
